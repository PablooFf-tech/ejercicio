Centro de Ayuda y Preguntas Frecuentes

Encuentra respuestas rápidas sobre la práctica y el repositorio.

¿Cómo clonar este repositorio?

Utiliza el comando git clone URL_DEL_REPOSITORIO en tu terminal para obtener una copia local en tu equipo.

¿Qué diferencia hay entre git fetch y git pull?

git fetch descarga los objetos y referencias del repositorio remoto sin modificar tus archivos locales. git pull realiza la descarga e integra los cambios automáticamente en tu rama de trabajo actual.
